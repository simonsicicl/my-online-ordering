## Commit 1 -- Fix Foundation SAM Template

**Branch**: `develop`
**File**: `infrastructure/foundation/template.yaml`
**Commit message**: `fix(infra): fix RDS public access, add parameter group and CloudWatch alarms`

### Problems

- `PubliclyAccessible: false` -- blocks `drizzle-kit push` from local machine (dev needs `true`)
- No RDS Parameter Group -- default `max_connections` is too high; Lambda concurrency will exhaust connections
- No CloudWatch Alarms -- no early warning on resource pressure
- No `DevMyIPCidr` parameter -- RDS Security Group has no inbound rule for local access

### Changes

#### New Parameter

```yaml
DevMyIPCidr:
  Type: String
  Description: "Your local IP CIDR for RDS access (e.g. 1.2.3.4/32)"
  Default: "0.0.0.0/0"
```

#### RDS Instance -- modify two properties

```yaml
PubliclyAccessible: true          # required for local migration in dev
DBParameterGroupName: !Ref RDSParameterGroup
```

#### New RDS Parameter Group

```yaml
RDSParameterGroup:
  Type: AWS::RDS::DBParameterGroup
  Properties:
    Description: "PostgreSQL 15 parameter group for my-ordering"
    Family: postgres15
    Parameters:
      max_connections: "87"        # 10 conns x 8 Lambdas + 7 buffer
```

#### New SNS Topic (alarm notifications)

```yaml
AlarmTopic:
  Type: AWS::SNS::Topic
  Properties:
    TopicName: !Sub "${Environment}-ordering-alarms"
```

#### New CloudWatch Alarms

| Alarm | Metric | Threshold |
| --- | --- | --- |
| RDS DB Connections | `DatabaseConnections` | > 70 for 5 min |
| RDS Free Storage | `FreeStorageSpace` | < 2 GB for 5 min |
| RDS CPU | `CPUUtilization` | > 80% for 5 min |

## Commit 5 -- Fix CI/CD Pipeline

**Branch**: `develop`
**File**: `.github/workflows/ci.yml`
**Commit message**: `fix(ci): replace pnpm with npm, add real SAM deploy steps`

### Issues

1. Uses `pnpm` -- project uses npm workspaces
2. All deploy steps are `echo "Deploying..."` placeholders
3. Lint/test steps will fail because no services have those scripts yet

### Fixed Pipeline Structure

```yaml
name: CI/CD

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  validate:
    name: Validate SAM Templates
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: aws-actions/setup-sam@v2
        with:
          use-installer: true
      - name: Validate foundation template
        run: sam validate --template infrastructure/foundation/template.yaml --lint

  build-and-test:
    name: Build & Typecheck
    runs-on: ubuntu-latest
    needs: validate
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm ci
      - name: Typecheck shared-types
        run: npm run typecheck --workspace=packages/shared-types

  deploy-dev:
    name: Deploy to Dev
    runs-on: ubuntu-latest
    needs: build-and-test
    if: github.ref == 'refs/heads/develop' && github.event_name == 'push'
    environment: dev
    steps:
      - uses: actions/checkout@v4
      - uses: aws-actions/setup-sam@v2
        with:
          use-installer: true
      - uses: aws-actions/configure-aws-credentials@v4
        with:
          aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID_DEV }}
          aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY_DEV }}
          aws-region: ap-northeast-1
      - name: Deploy foundation
        working-directory: infrastructure
        run: |
          sam build --template foundation/template.yaml
          sam deploy --config-env dev --no-confirm-changeset --no-fail-on-empty-changeset

  deploy-prod:
    name: Deploy to Prod
    runs-on: ubuntu-latest
    needs: build-and-test
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    environment: prod
    steps:
      - uses: actions/checkout@v4
      - uses: aws-actions/setup-sam@v2
        with:
          use-installer: true
      - uses: aws-actions/configure-aws-credentials@v4
        with:
          aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID_PROD }}
          aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY_PROD }}
          aws-region: ap-northeast-1
      - name: Deploy foundation
        working-directory: infrastructure
        run: |
          sam build --template foundation/template.yaml
          sam deploy --config-env prod --no-confirm-changeset --no-fail-on-empty-changeset
```

## Step 6 -- AWS Bootstrap + Deploy (not a code commit)

> This step produces no git commit. It runs the deployment scripts to bring the AWS dev environment online.

### Execution Order

```powershell
# Step 1: IAM bootstrap (one-time per account)
.\scripts\bootstrap-iam.ps1 -Environment dev

# Step 2: Set GitHub Secrets (manual, in GitHub UI)
# AWS_ACCESS_KEY_ID_DEV / AWS_SECRET_ACCESS_KEY_DEV

# Step 3: Deploy foundation stack
.\scripts\deploy-foundation.ps1 -Environment dev

# Step 4: Write secrets to SSM Parameter Store
.\scripts\bootstrap-ssm.ps1 -Environment dev

# Step 5: Run DB migration
.\scripts\migrate.ps1 -Environment dev

# Step 6: Verify deployment
.\scripts\verify-deployment.ps1 -Environment dev
```

### Completion Checklist

- [ ] `infrastructure/params/dev.outputs.json` generated
- [ ] RDS instance status: `available`
- [ ] ElastiCache cluster status: `available`
- [ ] Cognito User Pool created
- [ ] All SSM parameters present (`verify-deployment.ps1` passes)

## Notes

### Commits 1-5 require no AWS access

Only a local `sam` CLI installation is needed to validate template syntax.

### Commit order must not be changed

- Commit 3 (root package.json) must come before Commit 4 (shared-types)
- Step 6 (AWS deploy) must come after Commits 1-5 are all merged

### `params/dev.json` contains no secrets

DB passwords, Stripe API keys, and other secrets are entered interactively via `bootstrap-ssm.ps1` and are never written to any file.

### Phase 2 prerequisite

Phase 2 (auth-service + first API service) depends on Step 6 completing successfully in order to obtain actual resource ARNs (e.g. Cognito User Pool ID, EventBridge bus ARN).
